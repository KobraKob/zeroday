# GCC Atlas — Front-End Audit

1. **Aesthetic Misalignment**: Uses generic SaaS dark-navy (#0f1b2d) and blue/orange pills instead of a citable paper/ink ledger aesthetic.
2. **Missing Footnote Architecture**: Datapoints lack true academic superscript citations (`[¹]`); evidence is relegated to standard modals.
3. **Pill-Based Confidence Badging**: Uses tech-startup colored rounded pills instead of stamp-like verification marks (Grades A–D).
4. **Weak Typographic Hierarchy**: Relies solely on sans-serif `Inter`, lacking a distinguished editorial serif (`Newsreader`) for findings and metrics.
5. **Startup-Slop Homepage**: Features centered hero buttons and identical card grids rather than a citable macro finding and direct reference pathways.
6. **Reconcile Not Led By Ledger**: Uses a detached Recharts bar chart rather than an integrated ruled table with proportional comparison bars.
7. **Lacks Inline Table Expansion**: Registry and Radar require page navigations instead of dense, expandable audit rows.
8. **Missing Data Hidden in Compare**: Empty city metrics render as blank text rather than explicit hatched ledger cells indicating unverified fields.
9. **No Unified Design Tokens**: Colors, borders, and typography are scattered as arbitrary Tailwind classes rather than CSS custom properties.
10. **Inadequate Mobile Margins**: No bottom-sheet drawer pattern for mobile footnote inspection; touch targets fall below 44px.
11. **Superficial Motion**: Transitions lack purpose; recomputed tallies lack an authoritative single-run count-up sequence.
12. **Promotional Copy Tone**: Uses marketing verbs ("Explore", "Browse") instead of neutral, archival, and citable statements of record.
